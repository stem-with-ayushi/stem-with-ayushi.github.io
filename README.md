## 🚀 How to Run Locally

You can run the site using Python's built-in server:

```bash
python3 -m http.server 8080
```

Then visit: **`http://localhost:8080`**

Or simply open `index.html` directly in any web browser!

## 🌐 How to Deploy for Free

1. **GitHub Pages**:
   - Create a repository on GitHub (e.g. `ayushi-singh-portfolio`).
   - Push these files to the `main` branch.
   - Go to **Settings → Pages** and choose `main` branch as the source.
2. **Netlify / Vercel**:
   - Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) for instant deployment in seconds.
